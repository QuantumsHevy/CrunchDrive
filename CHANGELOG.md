# Changelog

All notable user-facing changes to CrunchDrive are documented in this file. This mod is compatible with Kerbal Space Program 1.12 unless noted otherwise. Version numbers should follow semantic versioning.

## v0.1.0

### Added

- Added the CASI-25 "Staladus" Crunch Drive.
- Added `VABOrganizer` support. All crunch drives will be listed under Crunch Drives within Engines.
- Added `CommunityTechTree` support.
